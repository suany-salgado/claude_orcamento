# claude_orcamento
Documentos para a criação de orçamento para incluir no projeto no ambiente claude

📥 BAIXAR TODOS OS ARQUIVOS](https://github.com/suany-salgado/claude_orcamento/archive/refs/heads/main.zip)


📋 Gerador de Orçamentos com Claude AI

Aprenda a criar orçamentos em PDF e Excel utilizando o Claude.ai, com instruções e arquivos de referência prontos para configurar seu projeto.

📂 Materiais disponíveis

Neste repositório você encontrará:

* Instruções do Projeto: texto para configurar o comportamento do Claude.
* Modelo de Orçamento: documento de referência para a geração dos orçamentos.
* Tabela de Preços: planilha com os valores utilizados na elaboração dos orçamentos.
* Resposta da IA: material complementar.

🚀 Como configurar no Claude.ai

1. Crie um projeto

1. Acesse https://claude.ai
2. Entre na seção Projetos.
3. Clique em Novo projeto.
4. Dê o nome Gerador de Orçamentos.

2. Configure as instruções

1. Baixe o arquivo Instruções do Projeto disponível neste repositório.
2. Abra o arquivo e copie seu conteúdo.
3. No Claude.ai, encontre a seção Instruções do projeto.
4. Cole o texto no campo correspondente.
5. Salve as instruções.

Atenção: o conteúdo desse arquivo deve ser colocado nas instruções do projeto, não na área de arquivos.

3. Adicione os arquivos de referência

Na seção Arquivos do projeto, faça o upload dos seguintes documentos:

* Modelo de Orçamento
* Tabela de Preços

Esses arquivos servirão como referências para a elaboração dos orçamentos.

4. Gere seu orçamento

Abra uma conversa dentro do projeto e solicite ao Claude a criação de um orçamento, informando os serviços, produtos ou quantidades desejadas.

O Claude utilizará as instruções configuradas e os documentos de referência disponíveis no projeto.

Revise os dados, valores e cálculos antes de utilizar os documentos gerados.
